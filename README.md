# InvestingAgents
## 使用方法
輸入 `strategy` 以及 `end_date`，`end_date` 務必是進場訊號的日期!

## Installation
Clone 這個專案:
```
git clone https://github.com/kevin0629/InvestingAgents.git
```

## 運作 backend
```
cd backend
```
剩餘步驟請參考[這份文件](./backend/README.md)


## 運作 investingagents
```
cd investingagents
```
剩餘步驟請參考[這份文件](./investingagents/README.md)
